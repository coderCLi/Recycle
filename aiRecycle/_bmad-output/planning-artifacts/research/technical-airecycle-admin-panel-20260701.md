## 亮点功能设计

### 1. 估价偏差监控

```
估价 vs 实际成交 → 偏差率自动计算
按品类汇总 → 高估/低估TOP10
一键优化：调低某品类成色系数
```

价值：AI估价模型的持续迭代引擎，是 VS 爱回收的核心壁垒。

### 2. 回收员积分排行

```
自动计算：单量/满意度/响应速度/准时率
金牌/银牌/铜牌 → 结算时差异化抽成
排行榜实时展示，激励自驱动
```

价值：比管理者催单有效 10 倍。

### 3. 零单用户唤醒

```
拍照估价但未下单的用户列表
一键推送订阅消息（加价/限时/优惠）
追踪唤醒转化率
```

价值：0 成本唤醒沉默用户。

### 4. 竞品价格监控

```
手动录入爱回收/闲鱼同类报价
自动对比 aiRecycle 估价是否在合理区间
高估/低估预警
```

价值：前期人工维护，后期可自动化。
