# EXPERIENCE.md — 富区旧家电回收

## Foundation

**Form-factor:** 微信小程序（uni-app Vue3），仅移动端竖屏。
**UI system:** 微信原生风格，参考 `{colors.primary-green}` 微信绿为主色调。
**Visual identity:** 参见 DESIGN.md。

## Information Architecture

```
小程序（用户端）
├─ 首页 = 相机（拍照入口 + 最近估价记录）
├─ 估价结果页（品类/价格/预约入口）
├─ 预约页（时间窗选择 + 地址确认）
├─ 订单列表（全部订单）
├─ 订单详情（状态 / 回收员 / 价格）
└─ 简单设置（手机号 / 帮助）

后管（Web）
├─ 侧边导航
│   ├─ 数据概览
│   ├─ 订单管理
│   ├─ 线下录入
│   ├─ 多端对比
│   ├─ 回收员管理
│   ├─ 品类定价
│   └─ 用户管理
└─ 内容区（表格+图表为主）

回收员端（小程序内嵌）
├─ 今日订单列表
├─ 订单详情（导航 / 签收 / 修改价格）
└─ 我的（今日统计 / 历史业绩）
```

## Voice and Tone

**用户端文案风格：** 口语化、直接、不给压力。
- 按钮：动词开头。"拍照看看值多少钱"而非"物品估价"
- 提示：像邻居说话。"预估区间，上门确认最终价"而非"AI模型估算结果仅供参考"
- 错误：安抚而非报错。"没拍清楚，换个角度再试一次？"

**后管文案风格：** 专业、简洁、数据驱动。
- 表格字段使用术语（"线上单量""线下金额""偏差率"）
- 操作按钮使用动词+"了"（"已派单""已完成"）

## Component Patterns

### 拍照→估价→预约 三步流

**原则：** 每步只做一件事，减少路径摩擦。

| 步骤 | 页面 | 用户动作 | < 时间 |
|:---:|------|------|:---:|
| 1 | 首页（相机） | 点击拍照 或 选相册 | 2秒 |
| 2 | 估价结果 | 看到价格，点"预约上门" | 5秒 |
| 3 | 预约 | 选时间窗，确认 | 10秒 |
| → | 确认页 | 看到确认信息 | — |

**总耗时 < 20秒。**

### 估价页设计

- 上部：用户拍摄的照片（可重新拍）
- 中部大字：**¥100-150**（`{colors.accent-orange}` 32px Bold）
- 下部灰字："预估区间，最终价格以回收员上门确认为准"
- 底栏：一个大按钮"预约上门回收"

### 订单状态可视化

```
待确认 → 已派单 → 回收员已出发 → 服务中 → 已完成
  🗓        👷        🚚            🔧        ✅
```

进行中订单显示进度条+回收员姓名+预计到达时间。已完成订单显示成交价+减碳数据。

### 回收员端签收流程

回收员到达用户地址 → 点击"开始服务" → 填写最终价格（可修改预估） → 用户当面确认（回收员手机展示确认页，用户点"确认"） → 微信支付到账 → 回收员点"完成"。

## State Patterns

| 状态 | 表现 |
|------|------|
| 加载中 | 相机图标旋转 + "识别中..." |
| 空状态 | 订单列表为空时显示"还没有订单，拍张照片试试？" + 跳转按钮 |
| 错误 | 识别失败："没拍清楚，换个角度再试一次？" + 重拍按钮 |
| 网络异常 | Toast提示"网络不太稳定，重试一下？" |
| 成功 | 订单完成：大面积绿色✅ + 成交价 + "旧物重生减碳XX克" + 分享按钮 |

## Interaction Primitives

- **拍照：** 点击大圆按钮 → 唤起系统相机。相册备选入口在按钮下方小字"或从相册选择"
- **返回：** 使用微信原生导航栏返回，不自定义
- **下拉刷新：** 订单列表支持
- **Toast：** 操作反馈用微信原生 Toast，1.5秒自动消失
- **确认弹窗：** 取消订单时弹出"确定取消吗？"

## Accessibility Floor

- 所有触控区域 ≥ 44×44px（微信规范）
- 文字与背景对比度 ≥ 4.5:1（WCAG AA）
- 价格数字不使用纯文字——配图标辅助理解
- 页面支持系统字体缩放

## Key Flows

**Flow 1: 新手第一次使用**

用户扫码/搜索进入 → 看到相机大按钮 → 点击拍照 → 2秒识别 → 看到价格 → 点"预约上门" → 微信手机号授权（首次） → 选时间 → 确认 → 完成。全程 < 30秒，零文字输入。

**Flow 2: 回访用户卖第二件**

打开小程序 → 直接看到相机按钮 → 拍照 → 估价 → 预约（时间地址自动填充上次） → 确认。全程 < 15秒。

**Flow 3: 回收员一天的工作**

早上打开回收员入口 → 看到今日6单列表 → 按顺序出发 → 每单前10分钟系统自动通知用户 → 到达点"开始服务" → 填价 → 用户确认 → 点"完成" → 自动跳下一单导航。

**Flow 4: 线下单补录**

磊哥/回收员手机或电脑打开后管 → 点"线下录入" → 选品类/填重量/填金额/选来源 → 保存 → 自动纳入统计数据。

## Responsive & Platform

- 目标平台：微信小程序（iOS+Android）。不支持iPad横屏和PC端。
- 适配：375px基准宽度，flex布局自适应 320-428px
- 键盘：预约页面地址输入框唤起键盘时，页面自动上移
- 相机权限：首次使用引导用户授权，拒绝后提供"从相册选择"备选
