## 1. 项目概述

| 项目 | 说明 |
|------|------|
| 应用名称 | **大连海创嗨创生活 1.0**（`manifest.json`） |
| 产品定位 | 全市统一综合服务入口，覆盖生活服务、回收价、积分商城、优惠券、卡券、会员、支付等 |
| 代码形态 | uni-app + Vue 3 + TypeScript 跨端工程 |
| 目标平台 | 微信小程序（主）、H5、可选 App（app-plus 配置已就绪） |
| 仓库包名 | `uni-preset-vue`（uni-app 脚手架遗留名，非业务名） |
| 后端风格 | `/abpapp/{Controller}/{action}.do`（历史 Java 风格接口） |
| 内部代号/品牌 | 惠多多（`hdd`）、创新汇（`custom`）、大连海创（`hihihi` 域名） |

**核心业务域**（从代码推断）：

- 首页 & 生活服务入口
- **回收价**（Tab「会员码」，路径 `pages/memberCode/index`）
- 积分商城（`package-intergral-mall`）、优惠券（`package-counpons-quan`）、卡券平台（`package-cards-platform`）
- 商户/门店/商品下单体系（`package-product-list`，体量最大）
- 会员中心（`package-member-center`）、资金/交易（`package-money-transactions`）
- 通用服务（学校、商户、地图、订阅、课后服务等）
- 账户能力（登录、实名认证、注销、设置、消息、反馈）

## 7. 请求封装与 API 体系

### 7.1 `utils/http.ts` 核心封装

统一入口 `http(api, data, extra)`，基于 `uni.request`，封装了加解密、登录、防重复、Loading、错误处理。

**`extra` 配置项**：

| 参数 | 默认 | 说明 |
|------|------|------|
| `title` | `""` | Loading 提示文字 |
| `mask` | `true` | 是否显示 Loading 蒙板 |
| `skipLogin` | `false` | 跳登录时是否跳过提示 |
| `catchRes` | `false` | 是否独立处理原始响应（返回完整 result） |
| `catchError` | `false` | 是否抛出异常到调用处 `catch` 处理 |
| `showFailToast` | `true` | fail 时是否提示 toast |
| `url` | `""` | 第三方完整 URL（有值则替换 api） |
| `encrypt` | `true` | 请求报文 AES 加密 |
| `decrypt` | `true` | 响应报文 AES 解密 |
| `login` | `false` | 是否需登录态验证 |
| `sign` | `false` | 是否验签（md5） |
| `header` | `{}` | 额外请求头 |
| `method` | `POST` | 请求方法 |
| `timeout` | `60000` | 超时（ms） |

**核心逻辑**：

1. **Token 处理**：请求前检查 `app_jw_token`，不存在则调用 `requestToken`（`api/requestToken.ts`）获取 token/iv 后重试。
2. **登录验证**：`login: true` 且未登录时，记录拦截请求（`beans.setInterceptedRequests`）并跳转登录，登录完成后自动重发。
3. **请求头**：自动注入 `token`、`Content-Type: application/json`、`channelType: mini`（扫码核销接口特殊处理为 `app`）。
4. **公共参数**：`data.appid`、`data.timestamp` 自动补全。
5. **验签**：`sign: true` 时按 key 首字母排序后 md5，写入 `header.sign`。
6. **加密**：`encrypt: true` 时 `bridgeSdk.aesEncrypt(data)` 加密请求体。
7. **防重复**：`requestingMap` 以 `{api,data,extra}` 为 key 防止重复请求，complete 时清理。
8. **响应解析**：
   - `catchRes: true` 直接返回原始 result
   - 解密态响应结构：`{ errcode, errmsg, rspData }`，`errcode == "0"` 成功，`aesDecrypt(rspData)` 后二次 JSON 解析，最终 `respcode == "0000"` 返回 `result.result`
   - `errcode`：`0` 成功 / `-1` 系统异常 / `-2` Token 失效 / `2` 未登录 / `SIGN_ERROR` 验签失败 / `9` 解密失败
   - Token 失效（`-2`）自动清 token、清用户信息并重新拉 token
   - 未登录（`2`）清用户信息、记录拦截请求并提示登录
9. **统一 Loading / Toast**：`loading.showLoading/hideLoading`、`Toast`。

**错误码速查**：

| errcode | 含义 |
|---------|------|
| `0` | 成功 |
| `-1` | 请求报文不正确、系统繁忙、系统异常 |
| `-2` | Token 失效或无效 |
| `2` | 用户未登录 |
| `SIGN_ERROR` | 验签失败 |
| `9` | 报文解密失败 |

## 12. 关键机制说明

### 12.1 登录拦截

- **页面级**：`pages.json` 页面配置 `needLogin: true`；路由拦截器 `interceptors/route.ts` 对 `navigateTo/reLaunch/redirectTo` 黑名单拦截，未登录调 `utils.toLogin()`。
- **跳转级**：`jumpPage({ url, needLogin: true })` 或 URL 参数 `?needLogin=true`。
- **接口级**：`http(url, data, { login: true })`。
- **登录后回调**：来源页定义 `__loadData__()` 方法，登录完成自动回调重走初始化逻辑。
- **Token 失效/未登录**：`http.ts` 中 `errcode == -2` 或 `2` 自动清 token/用户信息，记录拦截请求待登录后重发。

### 12.2 实名认证

`this.bridgeSdk.checkIdentityAuth()`：校验是否实名，未实名自动拉起实名流程。实名页面见 `pages/identity-auth/`。

### 12.3 加解密机制

- 请求/响应默认 AES 加解密（`encrypt`/`decrypt` 可关）。
- 代码中预留国密 SM4 注释（`sm.js`），当前走 `bridgeSdk.aesEncrypt/aesDecrypt`。
- RSA 加密：`bridgeSdk.encryptString()`。
- 验签：`sign: true` 时按字母排序 + md5。
- **并发注意**：多个异步请求同时发起时，`getToken` 与本地会生成多对密钥/偏移量，可能因密钥不一致导致解密异常（`Error: Malformed UTF-8 data`）。**开发时应使用 `await` 串行处理并发请求**（微信小程序首次进入无缓存时必现）。

### 12.4 埋点统计

- 调用 `this.trackCustom(eventName, extraJson)` 自定义埋点。
- 已集成：页面跳转、接口请求、`jumpPage` 关键节点自动埋点（无需重复埋点）。
- 小程序用百度移动统计 `mtj-wx-sdk`；H5/App 埋点见 `utils/track.ts`。

### 12.5 页面跳转（`jumpPage`）

统一跳转方法，支持系统内页面、小程序跳转、外部 H5、打电话、扫码，并支持登录验证、实名验证、人脸验证；支持动态参数解析（`dynamicParamsToStaticParams`，见 README「太行步道/停车/文明专区」示例）。

### 12.6 数字精度

金额、价格统一用 `this.bridgeSdk.decimal.plus/minus/multiply/divide/eq`，避免浮点精度丢失。

### 12.7 分享功能

- 右上角全局分享：页面定义 `onShareAppMessageData` + `onShareAppMessage`（必须写，否则小程序分享灰显）。
- 按钮分享：`<vc-share :props-data="shareFriendData" />`。

### 12.8 状态栏与导航栏

全局 `navigationStyle: custom`。三种方式：

1. **推荐**：页面配置 statusBar/navigationBar 字段 + 使用 `vc-container` 根组件。
2. 页面直接使用 `<vc-status-bar />` + `<vc-navbar />`。
3. 完全自定义：`mapState(useBaseStore, ['navigationBarInfo'])` 获取高度自行处理。

## 15. 常见问题与坑

1. **启动后 API 404**：确认使用正确的 `dev:mp-weixin-*` / `dev:h5-*`，检查 `VITE_SERVER_BASEURL`。
2. **并发请求解密异常**（`Error: Malformed UTF-8 data`）：多个接口并发导致 token/iv 错配，改用 `await` 串行。
3. **登录态**：Token 存 storage 键 `app_jw_token`；请求头由 `interceptors/request.ts` 注入。
4. **自定义导航**：全局 `navigationStyle: custom`，需自行处理顶栏或用公共组件。
5. **H5 switchTab bug**：App 内 H5 的 `uni.switchTab` 无法返回首页，需用 `location.href = "/#/pages/home/home"`。
6. **sdk 编译失败**：`static` 下某些 SDK 偶发读不到，可挪到 `utils/library/sdk` 下。
7. **低版本手机 `Array.at` 报错**：已由 `prototypeInterceptor` polyfill 处理。
8. **`firstInit()` 方法已废除**：请勿继续使用。
